## Changes Since 0.0.10 (What to Test)

0.1.0 is a **packaging and versioning** release. No new features or behaviour changes since 0.0.10. The following are what differ from 0.0.10 and what to verify when testing the .vsix:

| Area | Change in 0.1.0 | What to test |
|------|------------------|--------------|
| **Version** | Bumped to 0.1.0 | Extension shows 0.1.0 in marketplace / About / extension details. |
| **Icon** | 256x256 `icon.png` (from icon2.png) included | Sidebar and extension detail view show the tech-globe + orbiting scripts icon. |
| **Package contents** | LICENSE, CHANGELOG, README; no extra icons or showcase doc | Install from .vsix; confirm extension runs and no stray files. |
| **Docs** | README marketplace-ready; CHANGELOG has 0.1.0 entry | Readme in extension tab is complete; changelog shows 0.1.0. |

**Regression / full sanity check (same as 0.0.10):**

- **Grapheme cursor (default on)**: Left/Right move by grapheme; cursor does not land inside emoji ZWJ, Indic conjuncts, or combining sequences.
- **Grapheme delete (default on)**: Backspace/Delete remove one grapheme cluster.
- **Hover inspector (default on)**: Hover shows codepoints, width, grapheme info.
- **Status bar**: Displays "UW Line/Sel: Nw Mg" for current line or selection.
- **Bidi visualization (opt-in)**: Setting `uniworld.showBidiVisualization` highlights LTR (blue) and RTL (orange) runs.
- **Visual bidi cursor (opt-in)**: Setting `uniworld.enableBidiVisualCursor` makes Left/Right follow visual direction in RTL text.
- **Line break decorations (opt-in)**: `uniworld.showLineBreakOpportunities` shows break markers.
- **Word select (opt-in)**: `uniworld.enableGraphemeWordSelect` + double-click uses script-aware word boundaries.
- **Commands**: Inspect Selection, Truncate to Display Width, Normalize NFC/NFD/NFKC/NFKD, Toggle Line Break Decorations, Select Word at Cursor.
- **Settings**: All seven UniWorld settings appear under Settings and toggle correctly.

Use `docs/UniWorld_Extension_Test_Guide.md` for detailed test cases. After installing the .vsix, run through the guide; if all pass, 0.1.0 is ready for publishing to the VS Code Marketplace.
