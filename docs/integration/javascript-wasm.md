# JavaScript / WebAssembly integration

This guide shows how to use UniWorld from JavaScript via WebAssembly.

## 1. Build the WASM package

Requirements:
- Rust toolchain
- `wasm-pack` (`cargo install wasm-pack`)

From the repo root:

```bash
wasm-pack build --release --features wasm --target bundler
```

This produces a package in `pkg/` with bindings generated by `wasm-bindgen`.

## 2. Use from a bundler (e.g. webpack, Vite)

Example (ES module):

```js
import init, {
  grapheme_boundaries,
  normalize_nfc,
  display_width,
} from "uniworld";

async function main() {
  await init(); // initialize the WASM module

  const text = "Hello, \u4e16\u754c \ud83d\udc4b";

  const g = grapheme_boundaries(text);
  console.log("grapheme breaks:", g);

  const nfc = normalize_nfc(text);
  console.log("NFC:", nfc);

  const w = display_width(text);
  console.log("display width:", w);
}

main();
```

## 3. API surface

The WASM module exposes a subset of the Rust APIs:

- Segmentation: `grapheme_boundaries`, `word_boundaries`, `sentence_boundaries`
- Normalization: `normalize_nfc`, `normalize_nfd`, `normalize_nfkc`, `normalize_nfkd`
- Case mapping: `to_lowercase`, `to_uppercase`, `to_titlecase`, `case_fold`
- Width and truncation: `display_width`, `truncate_graphemes`, `truncate_display_width`
- Cursor: `move_right`, `move_left`

Consult the generated TypeScript definitions (if using `wasm-pack build --target bundler`) for exact signatures.
