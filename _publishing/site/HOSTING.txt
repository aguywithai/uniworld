UniWorld static site - deploy and DNS
=====================================

Canonical project page URL:
  https://aguywithai.world/opensource/uniworld/

1) aguywithai.world (Next.js, Astro, or static public/)
-------------------------------------------------------
Copy from this folder into your site so paths exist:

  opensource/index.html
  opensource/uniworld/index.html
  style.css            (at site root next to opensource/, see below)

Required layout on the host:

  public/style.css
  public/opensource/index.html
  public/opensource/uniworld/index.html

opensource/index.html uses href="../style.css"
opensource/uniworld/index.html uses href="../../style.css"

If your framework uses only /public without a parent "style.css" at domain root,
either:
  - move style.css to public/opensource/uniworld/style.css and adjust both HTML
    files to load from that single path, or
  - duplicate style.css into each directory and use href="style.css" in each
    HTML file (simplest mental model).

2) uniworld.world -> 301 to canonical
--------------------------------------
At your DNS or CDN (example: Cloudflare):

  Source: uniworld.world (and www.uniworld.world)
  Destination: https://aguywithai.world/opensource/uniworld/
  Status: 301 Permanent Redirect

Cloudflare: Rules -> Redirect Rules, or "Bulk Redirects".

Other hosts: use their "redirect" or "aliases" feature to the full https URL.

3) GitHub Pages (uniworld repo only, optional)
----------------------------------------------
You can publish only _publishing/site/ as the Pages root. The root index.html
still declares rel=canonical to aguywithai.world so search engines prefer the
main site. Prefer not to duplicate long-term; use Pages as a mirror or retire
it once aguywithai is live.

4) Verification
---------------
After deploy, open:
  https://aguywithai.world/opensource/
  https://aguywithai.world/opensource/uniworld/
Check stylesheet loads and breadcrumbs work.
