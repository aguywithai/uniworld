UniWorld

Correct Unicode text handling for every script.

Bidirectional layout (UAX #9), line breaking (UAX #14), text segmentation (UAX #29), normalization (UAX #15), display width, and cursor navigation — one spec-aligned Rust core with bindings for Python, JavaScript/WASM, C, and Go. Developer tools include a VS Code extension and a PowerShell module.

The problem

Emoji split by the cursor, combining marks orphaned by backspace, bidi layout wrong in RTL text, CJK column counts wrong in terminals, truncation mid-grapheme. The Unicode Consortium publishes the algorithms; complete implementations are rare. UniWorld implements them in one place and ships them everywhere.
